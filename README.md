# Amazon Sales Analysis Dashboard


An interactive Tableau dashboard designed to analyze Amazon sales performance and uncover key business trends across product categories, order statuses, regions, and customer segments.

##  Dashboard Overview

This dashboard provides a comprehensive view of Amazon sales data through multiple visualizations, including:

- *Sales by Category* – Compares revenue generated across different product categories.
- *Order Status Distribution* – Analyzes the distribution of orders based on their current status.
- *Sales Trend Over Time* – Shows how sales revenue changes across different months.
- *Top States by Revenue* – Identifies the states contributing the highest sales revenue.
- *B2B vs B2C Revenue* – Compares revenue generated from business-to-business and business-to-consumer sales.

##  Key Analysis Areas

- Product category performance
- Order fulfillment and status distribution
- Monthly sales trends
- Geographic sales performance
- B2B vs B2C revenue comparison


##  Project Objective

The objective of this project is to transform Amazon sales data into an interactive dashboard that makes it easier to understand sales performance, identify high-performing categories and regions, analyze order statuses, and compare B2B and B2C revenue.
